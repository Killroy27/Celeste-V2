# Céleste — site web

Landing page de Céleste, la marketplace mariage et événementiel (Next.js 15, React 19, TypeScript, CSS Modules).

## Lancer en local

```bash
npm install
npm run dev
```

Puis ouvrir http://localhost:3000.

## Structure

- `src/app/` : layout (polices Bodoni Moda + DM Sans), styles globaux et tokens de la charte, page d'accueil
- `src/components/` : en-tête collant et recherche, hero avec mur d'inspiration, onglets métiers, catalogue
- `src/lib/content.ts` : contenu de démonstration, à remplacer par l'API
- `public/` : photos, icônes 3D et logo
